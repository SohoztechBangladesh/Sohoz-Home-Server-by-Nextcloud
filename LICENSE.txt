1. OVERVIEW AND DUAL-LICENSING STRUCTURE
----------------------------------------
Sohoz Home Server is an integrated home cloud solution designed as a private,
self-hosted alternative to third-party cloud storage providers such as Google
Drive, Microsoft OneDrive, and Apple iCloud Drive.

The software architecture consists of two distinct components:

A. Nextcloud Server Core (Open-Source Backend Engine)
B. Sohoz Home Server Windows Suite (Proprietary Manager & Orchestration Controller)
